Lesson 3 — Type Conversion + Input/Output

Ye topic important hai because real applications mein data hamesha correct type mein nahi milta.

Example:

User enters:
"21"


But application needs:
21

Yahan type conversion ki zarurat padti hai.

1. Type Conversion kya hai?

Ek data type ki value ko doosre data type mein convert karna type conversion hai.

Example:

int age = 21;


double newAge = age;

Yahan:

int
 ↓
double

conversion ho raha hai.

2. Two Main Types

C# mein broadly do situations samjho:

Type Conversion
      ↓
 ┌──────────────┐
 ↓              ↓
Implicit      Explicit
Conversion    Conversion
3. Implicit Conversion

Jab conversion automatically safely ho sakta hai, compiler conversion kar deta hai.

Example:

int age = 21;


double value = age;

int ki value double mein automatically convert ho sakti hai.

Conceptually:

21
 ↓
21.0

Example:

int marks = 85;
double percentage = marks;


Console.WriteLine(percentage);

Output:

85

Conceptually value double type ki hai.

4. Explicit Conversion / Casting

Jab automatic conversion possible nahi hota ya tum specifically conversion karna chahte ho, casting kar sakte ho.

Syntax:

(targetType)value

Example:

double price = 99.99;


int value = (int)price;


Console.WriteLine(value);

Output:

99

Decimal portion remove ho gaya.

99.99
 ↓
(int)
 ↓
99
Important

Casting rounding nahi karta.

99.99 → 99

not:

99.99 → 100
5. Convert Class

C# mein Convert class bhi conversion ke liye use hoti hai.

Example:

string ageText = "21";


int age = Convert.ToInt32(ageText);


Console.WriteLine(age);

Flow:

"21"
 ↓
Convert.ToInt32()
 ↓
21

Yahan input initially string hai, but hume int chahiye.

6. Parse()

Numbers ko string se convert karne ka common method:

int age = int.Parse("21");

Example:

string marksText = "85";


int marks = int.Parse(marksText);


Console.WriteLine(marks);

Output:

85
7. TryParse()

Real applications mein invalid input handle karne ke liye TryParse() bahut useful hai.

Example:

string input = "21";


bool success = int.TryParse(input, out int age);


Console.WriteLine(success);
Console.WriteLine(age);

Output:

True
21

Agar:

string input = "Hello";

toh conversion fail ho sakta hai without throwing the normal parsing exception.

bool success = int.TryParse(input, out int age);


Console.WriteLine(success);

Output:

False

TryParse() ka detailed use hum exception handling ke context mein bhi strengthen karenge.

8. Parse() vs TryParse() vs Convert
Method	Basic Use
Cast (int)	Compatible numeric conversion
Convert.ToInt32()	Convert values to int
int.Parse()	String → int
int.TryParse()	Safely attempt string → int

Beginner ke liye important:

Simple conversion → Convert
Known-valid numeric string → Parse
User input / uncertain input → TryParse

Ab sabse important part.

User se input lene ke liye:

Ye bahut important concept hai.

Suppose:

age ke andar value:

hai.

It is text/string, not an integer.

 ↓

 ↓
21

16. Better Approach — TryParse()

User kuch bhi enter kar sakta hai.

For example:

Enter age: abc

Agar tum:

int age = int.Parse(Console.ReadLine());

use karoge, invalid input par exception aa sakta hai.

Better:

Console.Write("Enter your age: ");


bool success = int.TryParse(Console.ReadLine(), out int age);


if (success)
{
    Console.WriteLine($"Your age is {age}");
}
else
{
    Console.WriteLine("Invalid age.");
}

Yahan:

Valid input
    ↓
success = true
    ↓
age available

Invalid input:

Invalid input
    ↓
success = false
    ↓
Invalid age

if ko hum next control-flow lesson mein deeply padhenge; abhi sirf structure samjho.

21. Common Mistakes
Mistake 1
int age = Console.ReadLine();

Problem: ReadLine() returns text, while age needs an int.

Correct:

int age = int.Parse(Console.ReadLine());
Mistake 2
double price = int.Parse(Console.ReadLine());

This can work through numeric conversion, but if the user is expected to enter decimal values, use:

double price = double.Parse(Console.ReadLine());
Mistake 3

Using Parse() without considering invalid user input.

For user-provided input, TryParse() is often safer.

22. Interview Questions
Q1. What does Console.ReadLine() return?

It reads a line of input from the console and returns it as a string.

Q2. How do you convert a string to an integer?
int.Parse("21");

or:

Convert.ToInt32("21");

or safely:

int.TryParse("21", out int number);
Q3. What is casting?

Explicitly converting a value to another compatible type.

double value = 99.99;
int number = (int)value;
Q4. What happens to 99.99 when cast to int?

The fractional portion is discarded, resulting in 99.

Q5. Why is TryParse() useful?

It allows you to attempt conversion and determine whether it succeeded without relying on an exception for normal invalid input.
