# **3. What is a for Loop?** 

A for loop is used to repeatedly execute a block of code while a specified condition is true. It is especially useful when the starting point, ending condition, and iteration pattern are known. 

# **4. Basic Syntax** 

for (initialization; condition; iteration) 

{ 

// code to execute 

} 

Example:
```for (int i = 1; i <= 5; i++) { 

Console.WriteLine(i);
} ```

2 

3 

4 

5

# **6. Initialization** 

Initialization runs **once** , before the loop starts. 

Example: 
```
for (int i = 1; i <= 5; i++); 
```
Here: 

int i = 1; 

is the initialization. 

It means the counter starts from 1. 

# **7. Condition** 

The condition determines whether the loop should continue. 

Example: 

i <= 5 

If the condition is: 

true 

the loop body executes. 

If the condition is: 

false 

the loop ends. 

# **8. Iteration** 

Iteration changes the loop variable after each iteration. 

Example: 

i++ 

This means: 

i = i + 1; 

So: 

1 → 2 → 3 → 4 → 5 → 6 

When i becomes 6: 

6 <= 5 

is false, so the loop ends.

# **10. continue with while** 

Example:

# **11. Important Warning with while** 

With while, you must be careful about updating the loop variable. 

Bad example: 

int i = 1; 

while (i <= 5) { if (i == 3) { continue; } 

Console.WriteLine(i); i++; } 

Problem: 

When i becomes 3: 

i == 3 ↓ continue ↓ i++ is skipped ↓ i remains 3 ↓ continue again ↓ continue again ↓ 

... 

This creates an infinite loop. 

### **Correct:** 

int i = 1; 

while (i <= 5) { i++; 

if (i == 3) { continue; } 

Console.WriteLine(i); } 

Or structure the loop carefully so the update always occurs.

# **20. Nested Loops and continue** 

continue affects the **nearest enclosing loop** . 

Example: for (int i = 1; i <= 2; i++) { for (int j = 1; j <= 3; j++) { if (j == 2) { continue; } Console.WriteLine($"i={i}, j={j}"); } } Output: i=1, j=1 i=1, j=3 i=2, j=1 

i=2, j=3 

The inner loop skips j == 2. 

The outer loop continues normally.

continue skips the remaining statements in the current iteration and proceeds toward the next iteration of the loop.

break    → terminates loop continue → skips current iteration 

### **Q4. Can continue be used with foreach?** 

Yes.

Yes.
