1. Operator kya hota hai?

Operator ek symbol/keyword hota hai jo values ya variables par operation perform karta hai.

Example:

int a = 10;
int b = 5;


int result = a + b;

Yahan:

a + b
↑   ↑
10  5


+ → Operator

Result:

15
2. Arithmetic Operators

Arithmetic operators mathematical calculations ke liye use hote hain.

Operator	Meaning
+	Addition
-	Subtraction
*	Multiplication
/	Division
%	Modulus / Remainder
Addition +
int a = 10;
int b = 5;


int result = a + b;


Console.WriteLine(result);

Output:

15
Subtraction -
int result = 10 - 5;


Console.WriteLine(result);

Output:

Multiplication *
int result = 10 * 5;


Console.WriteLine(result);

Output:

50
Division /
int result = 10 / 5;


Console.WriteLine(result);

Output:

2
Important: Integer Division
int result = 10 / 3;


Console.WriteLine(result);

Output:

3

Why?

Because both operands are int, so integer division is performed and the fractional part is discarded.

10 / 3 = 3.333...


int → 3

Agar decimal result chahiye:

double result = 10.0 / 3.0;


Console.WriteLine(result);
3. Modulus %

% remainder return karta hai.

int result = 10 % 3;


Console.WriteLine(result);

Output:

1

Because:

10 ÷ 3


3 × 3 = 9


10 - 9 = 1

So:

10 % 3 = 1
Real-world use

Even/odd check mein % extremely useful hai.

int number = 10;


Console.WriteLine(number % 2);

Output:

0

Agar:

number % 2 == 0

toh number even hai.

Odd:

number % 2 != 0

Ye concept hum if statements mein properly use karenge.

9. AND &&

&& ka meaning:

Dono conditions true honi chahiye.

Example:

int age = 21;
bool hasId = true;


Console.WriteLine(age >= 18 && hasId);

Output:

True

Concept:

age >= 18 → True
hasId     → True


True && True
     ↓
   True

Agar ek bhi false:

True && False
     ↓
   False
10. OR ||

|| ka meaning:

At least one condition true honi chahiye.

Example:

bool hasEmail = true;
bool hasPhone = false;


Console.WriteLine(hasEmail || hasPhone);

Output:

True

Because:

True || False
     ↓
   True

Dono false:

False || False
     ↓
   False

!True

13. Decrement Operator --

Variable ki value 1 se decrease karta hai.

Output:

Equivalent:

count = count - 1;
14. Prefix vs Postfix

Ye thoda important hai.

Postfix
int x = 5;


int y = x++;

Conceptually:

y = 5
x = 6

Pehle old value use hui, phir increment hua.

Prefix
int x = 5;


int y = ++x;

Conceptually:

x = 6
y = 6

Pehle increment hua, phir value use hui.

Remember
x++ → use first, increment later


++x → increment first, use later

16. Ternary Operator ?:

Ternary operator short form of simple if-else hai.

Syntax:

condition ? valueIfTrue : valueIfFalse

Example:

int age = 21;

Console.WriteLine(result);

Output:

Concept:

age >= 18 ?
    ↓
 True → "Adult"
 False → "Minor"

Abhi if-else hum next control-flow section mein properly padhenge.

17. Operator Precedence

Ek expression mein multiple operators ho sakte hain.

Example:

int result = 10 + 5 * 2;

Output:

20

Not:

30

Why?

Multiplication first:

5 * 2 = 10


10 + 10 = 20
Parentheses

Parentheses priority change kar sakte hain.

int result = (10 + 5) * 2;

Now:

10 + 5 = 15


15 * 2 = 30

Output:

30
Basic Rule
()
 ↓
* / %
 ↓
+ -
 ↓
Comparison
 ↓
Logical
 ↓
Assignment

Exact precedence list bahut large hai; abhi practical order yaad rakho.

21. Common Beginner Mistakes
Mistake 1

Wrong for comparison.

Correct:

if (age == 18)
Mistake 2 — Integer division
int result = 5 / 2;

Result:

Not 2.5.

For decimal calculation:

double result = 5.0 / 2.0;
Mistake 3 — Confusing %
10 % 3

doesn't mean percentage.

It means:

remainder after division.

Result:

1
Mistake 4 — Confusing && and ||
&& → both conditions need to be true


|| → at least one condition needs to be true
22. Interview Questions
Q1. Difference between = and ==?
=  → Assignment
== → Equality comparison
Q2. What does % do?

Returns the remainder of a division.

Q3. What is &&?

Logical AND. It returns true when both conditions are true.

Q4. What is ||?

Logical OR. It returns true when at least one condition is true.

Q5. What does ! do?

It logically negates a boolean value.

Q6. Difference between x++ and ++x?
x++ → use current value, then increment


++x → increment first, then use value
Q7. What is the ternary operator?

A compact conditional expression:

condition ? trueValue : falseValue;
