2. What is an Array?

An array is a collection of elements of the same data type, stored under one variable name.

Suppose you want to store 5 numbers.

Without an array:

int number1 = 10;
int number2 = 20;
int number3 = 30;
int number4 = 40;
int number5 = 50;

This works, but becomes difficult when you have many values.

With an array:

int[] numbers = { 10, 20, 30, 40, 50 };

Now all five values are stored under:

numbers
3. Why Do We Need Arrays?

Imagine storing marks of 100 students.

Without an array:

student1Marks
student2Marks
student3Marks
...
student100Marks

This would be difficult to manage.

With an array:

int[] marks = new int[100];

Now one variable represents the complete collection.

Concept:

One Variable
     ↓
┌────┬────┬────┬────┬────┐
│ 10 │ 20 │ 30 │ 40 │ 50 │
└────┴────┴────┴────┴────┘
4. Important Characteristics of Arrays

A normal C# array has some important characteristics:

1. Same data type
int[] numbers = { 10, 20, 30 };

All elements are int.

You cannot normally mix unrelated types:

int[] numbers = { 10, "Hello", 30 };

This is invalid.

2. Fixed length

Once an array is created, its length is fixed.

Example:

int[] numbers = new int[5];

This array has exactly:

5 elements

You cannot simply make it 10 elements by assigning:

numbers.Length = 10

Length is read-only.

If you need a dynamically growing collection, later we will study List<T>.

3. Index-based access

Each element has an index.

Index:
  0    1    2    3    4
  ↓    ↓    ↓    ↓    ↓
┌────┬────┬────┬────┬────┐
│ 10 │ 20 │ 30 │ 40 │ 50 │
└────┴────┴────┴────┴────┘
5. Array Indexing

C# arrays are zero-indexed.

This means the first element has index:

0

Not:

1

Example:

int[] numbers = { 10, 20, 30, 40, 50 };
Index	Value
0	10
1	20
2	30
3	40
4	50

The last index is:

Length - 1

So:

Length = 5
Last index = 4
6. Declaring an Array

Basic syntax:

dataType[] arrayName;

Example:

int[] numbers;

At this point, we have declared the variable, but we have not created an array object yet.

7. Creating an Array
int[] numbers = new int[5];

This creates an array capable of storing 5 integers.

Conceptually:

numbers
   ↓
┌────┬────┬────┬────┬────┐
│ 0  │ 0  │ 0  │ 0  │ 0  │
└────┴────┴────┴────┴────┘
  0    1    2    3    4

Because int is a value type, newly created int array elements are initialized to 0.

12. Updating an Array Element

Array elements can be changed using their index.

int[] numbers = { 10, 20, 30, 40, 50 };

numbers[2] = 100;

Console.WriteLine(numbers[2]);

Output:

100

Before:

Index:  0   1   2   3   4
Value: 10  20  30  40  50

Value: 10  20  100 40  50
13. Length Property

Length tells you how many elements the array contains.

int[] numbers = { 10, 20, 30, 40, 50 };

Console.WriteLine(numbers.Length);

Output:

5

Remember:

Length = number of elements
14. Length vs Last Index

This is extremely important.

Suppose:

int[] numbers = { 10, 20, 30, 40, 50 };

Then:

Length = 5

But:

Last Index = 4

Formula:

Last Index = Length - 1

Therefore:

5 - 1 = 4
15. Traversing an Array with for

The standard pattern:

int[] numbers = { 10, 20, 30, 40, 50 };

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

Output:

10
20
30
40
50

Why:

i = 0 → numbers[0]
i = 1 → numbers[1]
i = 2 → numbers[2]
i = 3 → numbers[3]
i = 4 → numbers[4]
i = 5 → stop
16. Why i < numbers.Length?

Suppose:

Length = 5

Valid indexes:

0
1
2
3
4

So:

i < 5

allows:

0, 1, 2, 3, 4

But:

i <= 5

would eventually attempt:

numbers[5]

which is invalid.

Therefore, the standard array traversal is:

for (int i = 0; i < numbers.Length; i++)
17. Traversing with foreach

If you don't need the index, foreach is simpler:

int[] numbers = { 10, 20, 30, 40, 50 };

foreach (int number in numbers)
{
    Console.WriteLine(number);
}

Output:

10
20
30
40
50
18. for vs foreach with Arrays
for
for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

You have the index:

i
foreach
foreach (int number in numbers)
{
    Console.WriteLine(number);
}

You directly get the value:

number
Simple Rule
Need index?
    ↓
   for

Only need values?
    ↓
 foreach

23. Find Maximum
int[] numbers = { 10, 50, 20, 80, 30 };

int max = numbers[0];

foreach (int number in numbers)
{
    if (number > max)
    {
        max = number;
    }
}

Console.WriteLine($"Maximum = {max}");

Output:

Maximum = 80

Logic:

max = 10

50 > 10 → max = 50
20 > 50 → no
80 > 50 → max = 80
30 > 80 → no

30. Array Index Out of Range

One of the most common array errors is accessing an invalid index.

Example:

int[] numbers = { 10, 20, 30 };

Valid indexes:

0
1
2

This is invalid:

Console.WriteLine(numbers[3]);

Because index 3 does not exist.

It results in an:

IndexOutOfRangeException
31. Common Mistake — Starting at 1

Incorrect:

for (int i = 1; i <= numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

Why?

Arrays start at index 0.

Correct:

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}
32. Common Mistake — Using <=

Incorrect:

for (int i = 0; i <= numbers.Length; i++)

Correct:

for (int i = 0; i < numbers.Length; i++)

Remember:

Length = 5
Last index = 4

So:

i < 5

is correct.

35. When Should You Use an Array?

Arrays are useful when:

You need multiple values of the same type.
The number of elements is known/fixed.
You need indexed access.
You want a simple fixed-size collection.

Example:

Days in a week → 7
Months in a year → 12
Fixed number of exam scores
Fixed-size data sets

For collections that need to grow or shrink dynamically, List<T> is usually more appropriate.

36. Interview Questions
Q1. What is an array?

An array is a fixed-size collection of elements of the same type, accessed using indexes.

Q2. What is the first index of a C# array?
0
Q3. If an array has 10 elements, what is the last index?
9

Because:

Last Index = Length - 1
           = 10 - 1
           = 9
Q4. What does Length return?

The number of elements in the array.

Q5. Can an array change its size after creation?

No. A normal array has a fixed length after creation.

Q6. What happens when you access an invalid index?

An IndexOutOfRangeException is thrown.

Q7. Difference between for and foreach for arrays?

for gives direct access to the index, while foreach directly provides each element.
