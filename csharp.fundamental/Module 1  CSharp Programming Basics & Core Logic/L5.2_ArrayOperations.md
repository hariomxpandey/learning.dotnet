3. Array Traversal

Traversal means:

Visiting every element of an array one by one.

Example:

int[] numbers = { 10, 20, 30, 40, 50 };

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}

Output:

10
20
30
40
50

Using foreach:

foreach (int number in numbers)
{
    Console.WriteLine(number);
}
Mental Model
Array
 ↓
Element 1
 ↓
Element 2
 ↓
Element 3
 ↓
...
 ↓
Last Element

Most array algorithms are built on this basic traversal.

4. Counting Elements

Suppose we want to count how many even numbers exist.

int[] numbers = { 10, 15, 20, 25, 30, 35 };

int count = 0;

foreach (int number in numbers)
{
    if (number % 2 == 0)
    {
        count++;
    }
}

Console.WriteLine($"Even numbers = {count}");

Output:

Even numbers = 3
Logic
number
   ↓
Is even?
   ↓
Yes → count++

8. Searching an Array

Searching means:

Checking whether a particular value exists in the array.

Example:

int[] numbers = { 10, 20, 30, 40, 50 };

int target = 30;
bool found = false;

foreach (int number in numbers)
{
    if (number == target)
    {
        found = true;
        break;
    }
}

Console.WriteLine($"Found = {found}");

Output:

Found = True
9. Search Without break

You can also write:

int[] numbers = { 10, 20, 30, 40, 50 };

int target = 30;
bool found = false;

foreach (int number in numbers)
{
    if (number == target)
    {
        found = true;
    }
}

Console.WriteLine($"Found = {found}");

This works.

But once the value is found, continuing to inspect the remaining elements may be unnecessary.

Therefore:

break;

can make the search more efficient.

10. Finding the Index

Sometimes we don't just want to know whether the value exists.

We want to know:

At which index does it exist?

Example:

int[] numbers = { 10, 20, 30, 40, 50 };

int target = 40;
int index = -1;

for (int i = 0; i < numbers.Length; i++)
{
    if (numbers[i] == target)
    {
        index = i;
        break;
    }
}

Console.WriteLine($"Index = {index}");

Output:

Index = 3

Why initialize:

int index = -1;

Because -1 can represent:

Value was not found.

Example:

target = 100
→ index remains -1

Now suppose we want the last occurrence.

int[] numbers = { 10, 20, 30, 20, 40 };

→ lastIndex = 1

No break, because we need to continue searching.

Consider:

Better:

18. Reverse an Array

Suppose:

Original:
10 20 30 40 50

Reversed:
50 40 30 20 10

One way is to create a new array:

int[] numbers = { 10, 20, 30, 40, 50 };

int[] reversed = new int[numbers.Length];

for (int i = 0; i < numbers.Length; i++)
{
    reversed[i] = numbers[numbers.Length - 1 - i];
}

foreach (int number in reversed)
{
    Console.WriteLine(number);
}

Output:

50
40
30
20
10
19. Understanding the Reverse Formula

The important part:

numbers[numbers.Length - 1 - i]

Suppose:

Length = 5

Indexes:

0  1  2  3  4

For:

i = 0

we access:

5 - 1 - 0 = 4

For:

i = 1

we access:

5 - 1 - 1 = 3

So:

0 → 4
1 → 3
2 → 2
3 → 1
4 → 0
20. Reverse Using Two Pointers

A more algorithmic approach is to swap elements from both ends.

int[] numbers = { 10, 20, 30, 40, 50 };

int left = 0;
int right = numbers.Length - 1;

while (left < right)
{
    int temp = numbers[left];

    numbers[left] = numbers[right];
    numbers[right] = temp;

    left++;
    right--;
}

foreach (int number in numbers)
{
    Console.WriteLine(number);
}

Output:

50
40
30
20
10
Visual
10 20 30 40 50
↑              ↑
left          right

50 20 30 40 10
   ↑          ↑
  left      right

50 40 30 20 10
      ↑  ↑
     left/right

This is an important algorithmic pattern:

Two-pointer technique

We will encounter this pattern again when studying algorithms.

21. Copying an Array Manually
int[] original = { 10, 20, 30, 40 };

int[] copy = new int[original.Length];

for (int i = 0; i < original.Length; i++)
{
    copy[i] = original[i];
}

Now:

original → 10 20 30 40
copy     → 10 20 30 40

They are separate arrays.

22. Important: Reference Assignment

This is different:

int[] original = { 10, 20, 30 };

int[] copy = original;

This does not create a new array.

Both variables refer to the same array.

Conceptually:

original ──┐
           ↓
      [10 20 30]
           ↑
copy ──────┘

Therefore:

copy[0] = 100;

will also affect what original[0] sees.

original[0] → 100
copy[0]     → 100

This is an important C# reference-type concept.

23. Comparing Arrays

This is a common beginner mistake.

Suppose:

int[] a = { 1, 2, 3 };
int[] b = { 1, 2, 3 };

This:

Console.WriteLine(a == b);

does not mean "do the arrays contain the same values?"

It checks whether the two variables refer to the same array object.

Since they are separately created arrays:

a → Array A
b → Array B

the result is:

False

even though their contents are equal.

24. Manual Array Comparison

To compare contents manually:

int[] a = { 1, 2, 3 };
int[] b = { 1, 2, 3 };

bool equal = true;

if (a.Length != b.Length)
{
    equal = false;
}
else
{
    for (int i = 0; i < a.Length; i++)
    {
        if (a[i] != b[i])
        {
            equal = false;
            break;
        }
    }
}

Console.WriteLine(equal);

Output:

True

Logic:

Same length?
   ↓
Yes
   ↓
Compare each index
   ↓
Any difference?
   ↓
Yes → false
No  → true
25. Find Duplicate Values

Suppose:

int[] numbers = { 10, 20, 30, 20, 40, 10 };

We can compare every element with later elements.

for (int i = 0; i < numbers.Length; i++)
{
    for (int j = i + 1; j < numbers.Length; j++)
    {
        if (numbers[i] == numbers[j])
        {
            Console.WriteLine($"Duplicate: {numbers[i]}");
        }
    }
}

Output:

Duplicate: 10
Duplicate: 20

This uses a nested loop.

Complexity is roughly:

O(n²)

for this basic approach.

We will study algorithmic complexity later in more depth.

27. Basic Sorting — Bubble Sort

Sorting means arranging values in order.

Example:

Before:
50 20 40 10 30

After:
10 20 30 40 50

A basic learning algorithm is Bubble Sort.

int[] numbers = { 50, 20, 40, 10, 30 };

for (int i = 0; i < numbers.Length - 1; i++)
{
    for (int j = 0; j < numbers.Length - 1 - i; j++)
    {
        if (numbers[j] > numbers[j + 1])
        {
            int temp = numbers[j];

            numbers[j] = numbers[j + 1];
            numbers[j + 1] = temp;
        }
    }
}

foreach (int number in numbers)
{
    Console.WriteLine(number);
}

Output:

10
20
30
40
50
28. How Bubble Sort Works

Suppose:

50 20 40 10 30

Compare adjacent elements:

50 > 20

Swap:

20 50 40 10 30

Next:

50 > 40

Swap:

20 40 50 10 30

Next:

50 > 10

Swap:

20 40 10 50 30

Next:

50 > 30

Swap:

20 40 10 30 50

Largest value has moved toward the end.

That is why it's called:

Bubble Sort

For production code, you normally use the framework's well-tested sorting facilities rather than implementing Bubble Sort yourself. The algorithm is useful here for learning loops, comparisons, and swapping.

29. Swapping Two Values

The basic swap pattern is extremely important.

Suppose:

a = 10
b = 20

We want:

a = 20
b = 10

Use a temporary variable:

int temp = a;
a = b;
b = temp;

Flow:

temp = 10
a = 20
b = 10

This pattern appears in:

Reversing arrays
Sorting
Algorithms
Two-pointer techniques
30. Empty Array

An array can have zero elements:

int[] numbers = Array.Empty<int>();

Then:

numbers.Length

is:

0

This matters when writing algorithms.

For example, this is dangerous for an empty array:

int max = numbers[0];

Because index 0 doesn't exist.

Therefore, before accessing numbers[0], you need to know that the array contains at least one element.

31. Common Mistakes
Mistake 1 — Length vs Last Index
Length = 5
Last Index = 4

Never confuse these.

Mistake 2 — Accessing numbers[Length]

Incorrect:

int[] numbers = { 10, 20, 30 };

Console.WriteLine(numbers[numbers.Length]);

This attempts:

numbers[3]

but valid indexes are:

0, 1, 2
Mistake 3 — Assuming Assignment Copies the Array
int[] b = a;

does not create a separate array.

Both variables refer to the same array.

Mistake 4 — Finding Maximum Starting from 0

Incorrect for arbitrary integer data:

int max = 0;

If the array contains only negative numbers, this gives the wrong result.

Better:

int max = numbers[0];

provided the array is non-empty.

Mistake 5 — Forgetting Empty Arrays

This:

int max = numbers[0];

requires at least one element.

Always consider:

Length == 0

when writing reusable code.

32. Important Array Patterns

You should start recognizing these patterns:

Pattern 1 — Traversal
for (int i = 0; i < array.Length; i++)
{
}
Pattern 2 — Counting
int count = 0;

foreach (int value in array)
{
    if (condition)
    {
        count++;
    }
}
Pattern 3 — Searching
bool found = false;

foreach (int value in array)
{
    if (value == target)
    {
        found = true;
        break;
    }
}
Pattern 4 — Maximum
int max = array[0];

foreach (int value in array)
{
    if (value > max)
    {
        max = value;
    }
}
Pattern 5 — Minimum
int min = array[0];

foreach (int value in array)
{
    if (value < min)
    {
        min = value;
    }
}

These patterns are more important than memorizing individual examples.

33. Interview Questions
Q1. What is array traversal?

Visiting each element of an array sequentially.

Q2. What is the difference between Length and the last index?
Length       → number of elements
Last index   → Length - 1
Q3. What does int[] b = a; do?

It makes b refer to the same array as a; it does not create a separate array.

Q4. How can you find the maximum without using a built-in method?

Start with the first element and compare every remaining element against the current maximum.

Q5. Why can a == b be false even when two arrays contain identical values?

Because array equality with == compares references, not the contents of separately created arrays.

Q6. What is Bubble Sort?

A simple sorting algorithm that repeatedly compares adjacent elements and swaps them when they are in the wrong order.

Q7. What is the basic time complexity of the nested-loop duplicate search?

Approximately:

O(n²)
