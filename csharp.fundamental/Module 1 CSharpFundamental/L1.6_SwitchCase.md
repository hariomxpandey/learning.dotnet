Lesson 6 — switch Statement in C#

Ab hum Control Flow ka next topic start karte hain: switch.

if-else ke baad switch samajhna important hai, especially jab hume ek value ke basis par multiple fixed options mein decision lena ho.

1. switch kya hai?

switch ek selection statement hai jo ek expression/value ko multiple possible cases ke saath compare karta hai.

Simple example:

int day = 2;


switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;


    case 2:
        Console.WriteLine("Tuesday");
        break;


    case 3:
        Console.WriteLine("Wednesday");
        break;


    default:
        Console.WriteLine("Invalid day");
        break;
}

Output:

Tuesday

Flow:

             day = 2
                ↓
        ┌───────┼───────┐
        ↓       ↓       ↓
      case 1  case 2  case 3
                ↓
            Tuesday
2. Basic Syntax
switch (expression)
{
    case value1:
        // code
        break;


    case value2:
        // code
        break;


    default:
        // code
        break;
}

Main parts:

switch
case
break
default
3. case

case possible value define karta hai.

Example:

int number = 10;


switch (number)
{
    case 10:
        Console.WriteLine("Number is 10");
        break;


    case 20:
        Console.WriteLine("Number is 20");
        break;
}

Because:

number = 10

therefore:

case 10
   ↓
Execute

Output:

Number is 10
4. break

break current switch statement se execution bahar nikal deta hai.

Example:

int option = 1;


switch (option)
{
    case 1:
        Console.WriteLine("Option One");
        break;


    case 2:
        Console.WriteLine("Option Two");
        break;
}

When case 1 matches:

case 1
  ↓
Execute code
  ↓
break
  ↓
Exit switch
5. default

Agar koi case match nahi karta, default execute hota hai.

int day = 8;


switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;


    case 2:
        Console.WriteLine("Tuesday");
        break;


    default:
        Console.WriteLine("Invalid day");
        break;
}

Output:

Invalid day
Simple understanding
Match found?
   ↓
Yes → matching case
   ↓
No → default

default optional hai, but generally useful hai.

9. Real-World Example — Menu

Suppose application mein menu hai:

1. Add Employee
2. View Employee
3. Update Employee
4. Delete Employee
5. Exit

switch is perfect for this kind of fixed-choice menu.

Console.WriteLine("1. Add Employee");
Console.WriteLine("2. View Employee");
Console.WriteLine("3. Update Employee");
Console.WriteLine("4. Delete Employee");
Console.WriteLine("5. Exit");


Console.Write("Choose an option: ");


int option = int.Parse(Console.ReadLine());


switch (option)
{
    case 1:
        Console.WriteLine("Add Employee selected");
        break;


    case 2:
        Console.WriteLine("View Employee selected");
        break;


    case 3:
        Console.WriteLine("Update Employee selected");
        break;


    case 4:
        Console.WriteLine("Delete Employee selected");
        break;


    case 5:
        Console.WriteLine("Exiting...");
        break;


    default:
        Console.WriteLine("Invalid option");
        break;
}

This pattern tumhe console applications aur later backend/business logic mein frequently milega.

10. if-else vs switch

Dono decision-making ke liye use hote hain, but use cases different ho sakte hain.

if-else

Complex conditions ke liye useful:

if (age >= 18 && hasId)
{
    Console.WriteLine("Allowed");
}

Yahan multiple logical conditions hain.

switch

Fixed values/options ke liye convenient:

switch (role)
{
    case "Admin":
        // ...
        break;


    case "User":
        // ...
        break;
}
Quick Comparison
if-else	switch
Conditions evaluate karta hai	Values/patterns ke cases handle karta hai
Complex conditions ke liye useful	Multiple fixed choices ke liye useful
>, <, &&, `	
Range checks ke liye useful	Menu/enum/state options ke liye useful
11. switch Expression

Modern C# mein switch expression bhi hota hai.

Traditional:

int day = 1;
string result;


switch (day)
{
    case 1:
        result = "Monday";
        break;


    case 2:
        result = "Tuesday";
        break;


    default:
        result = "Invalid";
        break;
}

Modern switch expression:

int day = 1;


string result = day switch
{
    1 => "Monday",
    2 => "Tuesday",
    3 => "Wednesday",
    _ => "Invalid"
};


Console.WriteLine(result);

Output:

Monday

Yahan:

1 → Monday
2 → Tuesday
3 → Wednesday
_ → Default

_ acts as the discard/default pattern in this context.

Abhi traditional switch par focus rakho. Switch expressions ko advanced C# ke context mein aur detail se dekhenge.

12. Important: break vs continue

Abhi break ko switch mein dekha.

break ka general meaning:

Current applicable control-flow construct se bahar nikalna.

continue ka use loops mein hota hai aur hum loops ke lesson mein properly padhenge.

Abhi bas:

switch → break
loop   → break / continue

yaad rakho.

13. Common Mistakes
Mistake 1 — break bhoolna

Traditional switch cases mein:

case 1:
    Console.WriteLine("One");
    break;

break important hai.

Mistake 2 — default ko case samajhna

default tab execute hota hai jab suitable case match nahi hota.

default:
    Console.WriteLine("Invalid");
    break;
Mistake 3 — Wrong data type
int option = 1;


switch (option)
{
    case "1":
        // ...
        break;
}

Yahan option int hai, but case "1" string hai.

Correct:

case 1:
14. Interview Questions
Q1. What is a switch statement?

switch is a selection statement used to execute code based on matching cases of an expression/value.

Q2. What is case?

case defines a possible matching value/pattern in a switch.

Q3. What is break?

It exits the current switch statement.

Q4. What is default?

It provides the fallback block when no applicable case matches.

Q5. When would you prefer switch over if-else?

When you have multiple discrete choices based on a value, such as menu options, roles, states, or enum values.

Q6. Can switch work with strings?

Yes.

string role = "Admin";


switch (role)
{
    case "Admin":
        Console.WriteLine("Admin");
        break;
}
