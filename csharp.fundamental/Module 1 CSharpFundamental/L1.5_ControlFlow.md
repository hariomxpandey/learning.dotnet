Lesson 5 — Control Flow: if, if-else, Nested if

Ab hum Module 1.2 — Control Flow Statements start kar rahe hain. Syllabus ke according control flow ka purpose hai decide karna ki program kaunsa code kab execute karega.

1. Control Flow kya hai?

Normally program statements top-to-bottom execute hote hain:

Statement 1
    ↓
Statement 2
    ↓
Statement 3
    ↓
Statement 4

Lekin real applications mein hume decisions lene padte hain.

Example:

Age >= 18 ?
    ↓
 Yes → Eligible
 No  → Not Eligible

Isi decision-making ko control flow kehte hain.

2. if Statement

if ka use condition check karne ke liye hota hai.

Syntax:

if (condition)
{
    // code
}

Example:

int age = 21;


if (age >= 18)
{
    Console.WriteLine("You are eligible.");
}

Output:

You are eligible.

Flow:

age >= 18?
    ↓
   True
    ↓
Execute code

Agar condition false hoti:

int age = 15;


if (age >= 18)
{
    Console.WriteLine("You are eligible.");
}

kuch print nahi hoga because condition false hai.

3. Condition kya hoti hai?

Condition generally ek expression hota hai jo true ya false produce karta hai.

Example:

age >= 18

Possible results:

21 >= 18 → true


15 >= 18 → false

Comparison operators jo humne previous lesson mein padhe:

==
!=
>
<
>=
<=

conditions mein commonly use hote hain.

4. if-else

Problem:

Sirf if mein false hone par kuch nahi hota.

Agar hume dono cases handle karne hain:

True  → A
False → B

toh if-else use karte hain.

Syntax:

if (condition)
{
    // true block
}
else
{
    // false block
}

Example:

int age = 15;


if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Minor");
}

Output:

Minor

Flow:

       age >= 18?
        /      \
      Yes      No
       ↓        ↓
    Adult     Minor
5. Real-World Example

Login system:

bool isLoggedIn = true;


if (isLoggedIn)
{
    Console.WriteLine("Welcome to Dashboard");
}
else
{
    Console.WriteLine("Please login first");
}

Possible output:

Welcome to Dashboard

Backend development mein isi type ki conditions repeatedly use hongi.

6. Multiple Conditions — else if

Suppose marks ke basis par result decide karna hai:

90+ → Excellent
75+ → Good
50+ → Average
Below 50 → Fail

Is situation mein else if use kar sakte hain.

int marks = 82;


if (marks >= 90)
{
    Console.WriteLine("Excellent");
}
else if (marks >= 75)
{
    Console.WriteLine("Good");
}
else if (marks >= 50)
{
    Console.WriteLine("Average");
}
else
{
    Console.WriteLine("Fail");
}

Output:

Good
7. else if ka Flow
marks >= 90?
    ↓ No


marks >= 75?
    ↓ Yes
   Good

Important:

Conditions top-to-bottom check hoti hain.

Jaise hi ek condition true hoti hai, us corresponding block ko execute karke chain se bahar aa jata hai.

8. Condition Order Matters

Example:

int marks = 95;


if (marks >= 50)
{
    Console.WriteLine("Pass");
}
else if (marks >= 90)
{
    Console.WriteLine("Excellent");
}

Output:

Pass

Why?

Because:

95 >= 50 → true

Pehli condition hi true ho gayi.

Isliye 90+ wali condition check nahi hui.

Correct order:

if (marks >= 90)
{
    Console.WriteLine("Excellent");
}
else if (marks >= 50)
{
    Console.WriteLine("Pass");
}
9. Nested if

Ek if ke andar another if ho sakta hai.

Isko nested if kehte hain.

Example:

int age = 21;
bool hasId = true;


if (age >= 18)
{
    if (hasId)
    {
        Console.WriteLine("Entry allowed");
    }
}

Flow:

Age >= 18?
    ↓ Yes
Has ID?
    ↓ Yes
Entry allowed
10. Nested if with else
int age = 21;
bool hasId = false;


if (age >= 18)
{
    if (hasId)
    {
        Console.WriteLine("Entry allowed");
    }
    else
    {
        Console.WriteLine("ID required");
    }
}
else
{
    Console.WriteLine("Not eligible");
}

Output:

ID required
11. Nested if vs Logical Operators

Sometimes nested if ki jagah && use kar sakte hain.

Nested:

if (age >= 18)
{
    if (hasId)
    {
        Console.WriteLine("Allowed");
    }
}

Can be expressed as:

if (age >= 18 && hasId)
{
    Console.WriteLine("Allowed");
}

Second version often cleaner hota hai when both conditions must be true.

12. if with &&
int age = 21;
bool hasId = true;


if (age >= 18 && hasId)
{
    Console.WriteLine("Allowed");
}

Both conditions true honi chahiye.

age >= 18 → true
hasId     → true


true && true
     ↓
   true
13. if with ||

Suppose user email ya phone se login kar sakta hai.

bool hasEmail = false;
bool hasPhone = true;


if (hasEmail || hasPhone)
{
    Console.WriteLine("Login method available");
}

Output:

Login method available

Because at least one condition true hai.

14. if with !
bool isBlocked = false;


if (!isBlocked)
{
    Console.WriteLine("Account is active");
}

!false becomes true.

15. Comparing Strings

Strings ko compare karne ke liye == use kar sakte hain.

string role = "Admin";


if (role == "Admin")
{
    Console.WriteLine("Admin Access");
}

Output:

Admin Access

Remember:

role = "Admin";

assignment hai.

role == "Admin"

comparison hai.

16. User Input + if

Ab previous lessons ko combine karte hain.

Console.Write("Enter your age: ");


int age = int.Parse(Console.ReadLine());


if (age >= 18)
{
    Console.WriteLine("You are an adult.");
}
else
{
    Console.WriteLine("You are a minor.");
}

Example:

Enter your age: 21
You are an adult.
17. Better: TryParse() + if

Real-world input mein invalid data aa sakta hai.

Console.Write("Enter your age: ");


bool isValid = int.TryParse(Console.ReadLine(), out int age);


if (isValid)
{
    Console.WriteLine($"Your age is {age}");
}
else
{
    Console.WriteLine("Invalid age.");
}

Yahan hum previous concepts combine kar rahe hain:

Input
 ↓
TryParse
 ↓
Validation
 ↓
if / else
 ↓
Output
18. Real-World Example — Login
string username = "admin";
string password = "1234";


if (username == "admin" && password == "1234")
{
    Console.WriteLine("Login successful");
}
else
{
    Console.WriteLine("Invalid credentials");
}

Concept:

Username correct?
       +
Password correct?
       ↓
 Login successful

20. Important Difference
if
if (condition)
{
}

Only true case handle karta hai.

if-else
if (condition)
{
}
else
{
}

True + false dono cases handle karta hai.

else if
if (...)
{
}
else if (...)
{
}
else
{
}

Multiple conditions handle karta hai.

Nested if
if (...)
{
    if (...)
    {
    }
}

Ek condition ke andar another condition.

21. Common Beginner Mistakes
Mistake 1 — = instead of ==

Wrong:

if (age = 18)

Correct:

if (age == 18)
Mistake 2 — Missing braces

For multiple statements:

if (age >= 18)
{
    Console.WriteLine("Adult");
    Console.WriteLine("Eligible");
}

Braces code block ko clearly define karti hain.

Mistake 3 — Wrong condition order

Wrong:

if (marks >= 50)
{
    Console.WriteLine("Pass");
}
else if (marks >= 90)
{
    Console.WriteLine("Excellent");
}

Better:

if (marks >= 90)
{
    Console.WriteLine("Excellent");
}
else if (marks >= 50)
{
    Console.WriteLine("Pass");
}
22. Interview Questions
Q1. What is control flow?

Control flow determines the order in which program statements execute.

Q2. What is an if statement?

It executes a block of code when a specified condition is true.

Q3. Difference between if and if-else?

if handles the true condition, while if-else provides an alternative block when the condition is false.

Q4. What is else if?

It allows multiple conditions to be checked sequentially.

Q5. What is nested if?

An if statement placed inside another if statement.

Q6. Can multiple else if blocks be used?

Yes.

if (...)
{
}
else if (...)
{
}
else if (...)
{
}
else
{
}
