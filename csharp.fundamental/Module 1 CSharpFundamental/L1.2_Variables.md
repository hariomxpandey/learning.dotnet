Practice
1. Variable kya hota hai?

Simple language mein:

Variable memory mein data store karne ke liye ek named location hota hai.

Example:

int age = 21;

Yahan:

int  → Data Type
age  → Variable Name
21   → Value
=    → Assignment Operator

Conceptually:

Memory
┌──────────────┐
│ age = 21     │
└──────────────┘

Baad mein value change bhi kar sakte ho:

int age = 21;


age = 22;

Ab:

age = 22
2. Variable Declaration

Variable ko declare karna means compiler ko batana:

"Mujhe is type ka ek variable chahiye."

Example:

int age;

Abhi variable declared hai, lekin value assign nahi hui.

int → type
age → name
3. Variable Initialization

Variable ko first time value dena initialization hai.

int age = 21;

Yahan declaration + initialization ek saath ho raha hai.

Alag-alag bhi kar sakte ho:

int age;


age = 21;
4. Declaration vs Initialization
Declaration
int age;
Initialization
age = 21;
Both Together
int age = 21;

Real development mein commonly third approach dikhegi.

5. Variable Naming Rules

C# variable ka naam rakhte waqt kuch rules follow karne padte hain.

Valid
int age;
string firstName;
double salary;
int studentAge;
Invalid
int 123age;       // Cannot start with number
string first-name; // - is not allowed

Variable name:

Letter se start ho sakta hai
_ se start ho sakta hai
Numbers use kar sakte ho, but first character number nahi hona chahiye
Spaces allowed nahi hain
C# keywords directly variable names ke roop mein use nahi kar sakte

Example:

int age2;
string firstName;
string _name;
6. C# is Case-Sensitive

Ye bahut important hai.

int age = 21;
int Age = 25;

age aur Age different identifiers hain.

Similarly:

Console
console

same nahi hain.

7. Data Type kya hota hai?

Data type batata hai:

Variable ke andar kis type ka data store hoga.

Example:

int age = 21;

int batata hai ki age integer/whole-number value store karega.

Different data:

21          → int
99.50       → double
"Hello"     → string
'A'         → char
true        → bool

9. int

int generally whole numbers store karne ke liye use hota hai.

int age = 21;
int marks = 85;
int salary = 30000;

Decimal value directly int mein nahi rakh sakte:

int price = 99.50;

Ye compile nahi hoga because 99.50 decimal/floating-point value hai.

10. long

long large whole numbers ke liye use hota hai.

long population = 1400000000;

Jab number int ki range se bada ho sakta hai, long useful hota hai.

11. float

float floating-point values ke liye use hota hai.

Example:

float temperature = 36.5f;

Notice:

36.5f
    ↑
    f

f batata hai ki literal ko float maana ja raha hai.

12. double

double bhi floating-point numbers ke liye commonly used type hai.

double height = 5.8;
double percentage = 89.19;

Generally double ka precision float se higher hota hai.

13. decimal

decimal high-precision decimal calculations ke liye commonly useful hai, especially financial/business calculations mein.

decimal price = 999.99m;
decimal salary = 45000.75m;

Notice:

999.99m
      ↑
      m

Example:

decimal productPrice = 1499.99m;
decimal tax = 270.00m;

For money-related calculations, decimal is generally preferred over float/double.

14. char

char ek single character store karta hai.

char grade = 'A';
char gender = 'M';
char symbol = '#';

char ke liye single quotes use hote hain:

'A'

Not:

"A"
15. string

string text store karne ke liye use hota hai.

string name = "Hariom";
string city = "Varanasi";
string course = "B.Tech CSE";

String ke liye double quotes:

"Hello"
16. char vs string

Very important:

char grade = 'A';
string name = "Hariom";

Difference:

char
 ↓
Single character


string
 ↓
Text / multiple characters

Examples:

char letter = 'H';


string word = "Hello";
17. bool

bool ka use true/false information ke liye hota hai.

bool isStudent = true;
bool isLoggedIn = false;
bool isActive = true;

Only two logical values:

true
false

Later if statements mein bool bahut important hoga.

Example:

bool isLoggedIn = true;


if (isLoggedIn)
{
    Console.WriteLine("Welcome");
}
18. Value Types vs Reference Types

C# mein types ko broadly value types aur reference types mein understand karna important hai.

Common Value Types
int
long
float
double
decimal
char
bool
struct
enum
Common Reference Types
string
class
object
array
interface
delegate

Abhi memory internals mein deep nahi jayenge. Bas basic distinction samjho.

Simple Idea

Value type variable generally apni value directly represent karta hai.

int a = 10;
int b = a;


b = 20;

Conceptually:

a → 10
b → 20

a ki value automatically 20 nahi ho jaati.

Reference types mein object/reference behavior different hota hai. Isko OOP/classes ke time detail mein padhenge.

19. var

C# mein compiler ko variable ka type infer karne ke liye var use kar sakte hain.

Example:

var age = 21;

Compiler understand karta hai:

age → int

Another example:

var name = "Hariom";

Compiler infer karega:

name → string

Similarly:

var price = 999.99m;

Type:

decimal
Important

var ka matlab dynamic type nahi hai.

Example:

var age = 21;


age = "Hariom";

Ye allowed nahi hai because age compile-time par int infer ho chuka hai.

20. Explicit Type vs var
Explicit
int age = 21;
string name = "Hariom";
decimal salary = 50000m;
var
var age = 21;
var name = "Hariom";
var salary = 50000m;

Dono cases mein compiler type know karta hai.

General rule:

var tab use karo jab inferred type obvious/readable ho.

21. const

const ka use constant value define karne ke liye hota hai.

Constant ki value initialization ke baad change nahi kar sakte.

const double Pi = 3.14159;

Ye incorrect hoga:

const int age = 21;


age = 22;

Because constant cannot be reassigned.

Another example:

const decimal GstRate = 18m;
22. Variable Reassignment

Normal variables ki value change kar sakte ho.

int age = 21;


Console.WriteLine(age);


age = 22;


Console.WriteLine(age);

Output:

21
22
23. Multiple Variables

Ek hi type ke multiple variables declare kar sakte ho:

int age = 21;
int marks = 85;
int semester = 4;

Ya:

int age = 21, marks = 85, semester = 4;

Lekin readability ke liye separate declarations often easier to understand hoti hain.

24. Variables with Output

Ab variables ko Console.WriteLine() ke saath use karte hain.

string name = "Hariom";
int age = 21;


Console.WriteLine(name);
Console.WriteLine(age);

Output:

Hariom
21
25. String + Variable

Simple concatenation:

string name = "Hariom";
int age = 21;


Console.WriteLine("Name: " + name);
Console.WriteLine("Age: " + age);

Output:

Name: Hariom
Age: 21
26. String Interpolation

Modern C# mein string interpolation bahut useful hai.

string name = "Hariom";
int age = 21;


Console.WriteLine($"Name: {name}");
Console.WriteLine($"Age: {age}");

Output:

Name: Hariom
Age: 21

$ string ko interpolated string banata hai.

$"Hello {name}"

{name} ke andar variable ki value insert hoti hai.

29. Common Mistakes
Mistake 1
int age = "21";

Wrong because "21" is a string.

Correct:

int age = 21;
Mistake 2
string name = Hariom;

Wrong.

Correct:

string name = "Hariom";
Mistake 3
char grade = "A";

Wrong because "A" is a string.

Correct:

char grade = 'A';
Mistake 4
bool status = "true";

Wrong.

Correct:

bool status = true;
Mistake 5
decimal price = 999.99;

For a decimal literal, use:

decimal price = 999.99m;
30. Interview Questions
Q1. What is a variable?

A variable is a named storage location used to hold a value.

Q2. What is a data type?

A data type specifies the kind of data a variable can represent.

Q3. Difference between declaration and initialization?
int age;       // Declaration


age = 21;      // Assignment/initialization

When written together:

int age = 21;

the variable is declared and initialized in one statement.

Q4. Is C# case-sensitive?

Yes.

age
Age
AGE

are different identifiers.

Q5. What is var?

var allows the compiler to infer the variable's static type from its initialization expression.

Q6. Is var dynamically typed?

No. var is statically typed after type inference.

Q7. What is const?

const defines a compile-time constant whose value cannot be reassigned.

Q8. Difference between char and string?

char represents a single character, while string represents text.

char letter = 'A';
string name = "Hariom";
